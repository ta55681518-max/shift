# 音声メモ（Xserver 版）設置手順

声で入力できるメモ帳です。項目ごとに入力でき、リマインドもかけられます。
**画面もサーバーもこのフォルダだけで完結**していて、Netlify は使いません。
自分の複数のiPhoneで同期できます（どれで書いても・直しても同じ内容になる）。
**アプリを閉じていてもリマインドが届きます**。
PHPだけで動くので、composer もデータベースも要りません。

```
memo/
├─ index.html          アプリの画面（デザインは OpenAI gpt-5.5 作）
├─ memo-sw.js          通知を出す係（Service Worker）
├─ memo.webmanifest    ホーム画面に追加したときの名前・アイコン
├─ memo-icon*.png      アイコン
└─ api/                サーバー部分（PHP）
   ├─ api.php          アプリとのやりとり・初回設定
   ├─ cron.php         毎分動かす：時間の来たリマインドを送る
   ├─ lib.php          共通部分（保存・Web Push の暗号化と署名）
   └─ data/            メモ本体と鍵（外からは見えない）
```

## 1. アップロード
1. この `memo` フォルダを、FTP（またはサーバーパネルのファイルマネージャー）で `/ドメイン名/public_html/memo/` にまるごとアップロードする
   - `api/data` フォルダと、その中の `.htaccess` も忘れずに入れる
2. サーバーパネルの「PHP Ver.切替」で **PHP 8.x** になっているか確認する
3. ドメインが **SSL（https）** になっているか確認する（「SSL設定」）。プッシュ通知には https が必要です

## 2. 初回設定（1回だけ）
1. ブラウザで `https://ドメイン名/memo/api/api.php?a=setup` を開く
2. **合言葉**（8文字以上）を決める

設定が終わると、同じページに次の2つが出ます。
- ① アプリのURL（`https://ドメイン名/memo/`）
- ② cron に登録するコマンド

## 3. cron（毎分）を登録
サーバーパネル →「Cron設定」→「Cron設定追加」で次のように入れます。
- 分・時間・日・月・曜日：すべて `*`
- コマンド：設定ページに出ている `/usr/bin/php8.3 /home/…/memo/api/cron.php > /dev/null 2>&1`
  - `php8.3` の部分は「PHP Ver.切替」のバージョンに合わせる
  - うまく動かないときは、設定ページで合言葉を入れると出る `curl -s "…api.php?a=cron&token=…"` のほうを使う（このURLは人に見せない）

cron が止まっていても、どれかのiPhoneでアプリを開けば、時間の過ぎた通知はそのとき送られます（保険）。

## 4. 各iPhoneでの設定（同期したいiPhoneすべてで）
1. Safari で `https://ドメイン名/memo/` を開く
2. 共有ボタン →「**ホーム画面に追加**」→ ホーム画面の「音声メモ」アイコンから開く
   - iPhoneは、ホーム画面から開いたときだけプッシュ通知を受け取れます（iOS 16.4 以上）
   - Safari とホーム画面のアイコンでは保存場所が別々なので、ここから先は必ずアイコンから開いて行う
3. ⚙設定 →「ほかのiPhoneと同期・サーバー通知」に **合言葉** を入れて「接続する」を押す
   - サーバーのURLは空のままでOK（同じ場所の `api/` を使います）
4. 「**この端末で通知を受け取る**」を押し、通知を「許可」する
5. 「サーバーから試す」を押して、数秒以内に通知が来ればOK

## うまくいかないとき
| 症状 | 対処 |
|---|---|
| 接続で「403」 | サーバーパネル →「WAF設定」で、そのドメインのWAFを一時的にOFFにして試す |
| 接続で「404」 | 置き場所が違う。`…/memo/api/api.php?a=info` をブラウザで開いて `{"ok":true…}` が出るか確認 |
| 「サーバーが未設定」 | `…/memo/api/api.php?a=setup` を開いて合言葉を決める |
| 「データが壊れています」 | FTPで `api/data/memo.json.bak` を `memo.json` に名前を変えて戻す |
| 通知ボタンを押しても何も起きない（iPhone） | ホーム画面のアイコンから開いているか確認する。iPhoneの設定 → 通知 →「音声メモ」がオンか確認する |
| 通知が時間どおりに来ない | Cron設定のコマンドとPHPのバージョンを確認する。設定ページのcurl版に替えてみる |
| 合言葉を変えたい | FTPで `api/data/config.json` を消して、`api.php?a=setup` を開き直す（各iPhoneで接続と通知の登録をやり直す） |

## バックアップ
- `api/data/memo.json`：メモ本体。ダウンロードしておけばバックアップになる
- `api/data/memo.json.bak`：1つ前の中身
- `api/data/config.json`：合言葉（ハッシュ）と通知用の鍵。**消すと通知の登録が全部やり直しになる**

## しくみのメモ（開発用）
- 同期は «変わったメモだけ送る → サーバーの全部を受け取る» の形。同じメモを2台で直したら、あとから送ったほうが残る（`rev`）
- 消したメモには `deleted` の印を60日残して、ほかの端末からも消えるようにしている
- 同期中のくり返しリマインドは、サーバー（cron）が次の回へ進める。画面側は表示するだけ
- 通知の送信が一時的に失敗した端末には、最大15回（約15分）送り直す
- Web Push は RFC 8291（aes128gcm）＋ VAPID（ES256）を、PHP の openssl で実装している
