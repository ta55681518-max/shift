# 音声メモ × Xserver 設置手順

`memo.html`（音声メモ）を、**スタッフのiPhoneで共有**し、**アプリを閉じていてもリマインドが届く**ようにするためのサーバー部分です。
PHPだけで動きます（composer・データベース不要）。

## できること
- メモ・項目を、同じ合言葉を入れた端末どうしで共有（30秒ごと＋開いたとき＋保存したときに同期）
- リマインドの時間になると、Xserver の cron（毎分）が **iPhone / Android にプッシュ通知**
- メモごとに「全員に通知」か「入れた人だけに通知」を選べる
- だれが入れたメモか（👤名前）が表示される

## 1. アップロード
1. このフォルダ `memo-api` を、FTP（またはサーバーパネルのファイルマネージャー）で
   `/ドメイン名/public_html/memo-api/` にまるごとアップロード
   - `data` フォルダと、その中の `.htaccess` も忘れずに（メモ本体と鍵が入る場所で、外からは見えない設定）
2. サーバーパネル →「PHP Ver.切替」で **PHP 8.x** になっていることを確認
3. ドメインが **SSL（https）** になっていることを確認（「SSL設定」）。プッシュ通知は https 必須

## 2. 初回設定（1回だけ）
ブラウザで `https://ドメイン名/memo-api/api.php?a=setup` を開き、**お店の合言葉**（8文字以上）を決める。
設定が終わると、同じページに次の2つが表示されます：
- ① アプリに入れるサーバーのURL
- ② cron に登録するコマンド

## 3. cron（毎分）を登録
サーバーパネル →「Cron設定」→「Cron設定追加」
- 分・時間・日・月・曜日：すべて `*`
- コマンド：設定ページに出ている `/usr/bin/php8.3 /home/…/memo-api/cron.php > /dev/null 2>&1`
  - `php8.3` は「PHP Ver.切替」のバージョンに合わせる
  - うまく動かないときは、設定ページに出ている `curl -s "…api.php?a=cron&token=…"` のほうを使う

> cron が止まっていても、だれかがアプリを開いたタイミングで、時間の過ぎた通知は送られます（保険）。

## 4. 各iPhoneでの設定
1. Safari で音声メモ（`https://comfy-khapse-8a3cae.netlify.app/memo.html`）を開く
2. 共有ボタン →「**ホーム画面に追加**」→ ホーム画面の「音声メモ」アイコンから開く
   （iPhoneは、ホーム画面から開いたときだけプッシュ通知を受け取れます。iOS 16.4 以上）
3. ⚙設定 →「みんなで共有・サーバー通知」に
   - サーバーのURL（例：`https://ドメイン名/memo-api/`）
   - お店の合言葉
   - 自分の名前（店長・田中など）
   を入れて「接続する」
4. 「**この端末で通知を受け取る**」→ 通知を「許可」
5. 「サーバーから試す」で数秒以内に通知が来ればOK

## うまくいかないとき
| 症状 | 対処 |
|---|---|
| 接続で「403」 | サーバーパネル →「WAF設定」で、そのドメインのWAFを一時的にOFFにして試す |
| 接続で「404」 | URLの場所が違う。`…/memo-api/api.php?a=info` をブラウザで開いて `{"ok":true…}` が出るか確認 |
| 「サーバーが未設定」 | `api.php?a=setup` を開いて合言葉を決める |
| 通知ボタンを押しても何も起きない（iPhone） | Safariではなく、ホーム画面のアイコンから開いているか確認。iPhoneの設定 → 通知 →「音声メモ」がオンか確認 |
| 通知が時間どおりに来ない | Cron設定のコマンドとPHPのバージョンを確認。設定ページのcurl版に替えてみる |
| 合言葉を変えたい | FTPで `data/config.json` を消して、`api.php?a=setup` を開き直す（各端末で接続と通知の登録をやり直し） |

## ファイル
- `api.php`：アプリとやりとりする入口（同期・通知の登録・初回設定）
- `cron.php`：毎分動かす。時間の来たリマインドを送る
- `lib.php`：共通部分（保存・Web Push の暗号化と署名）
- `data/config.json`：合言葉（ハッシュ）・通知用の鍵。**消すと通知の登録が全部やり直しになる**
- `data/memo.json`：メモ本体。バックアップしたいときはこれをダウンロード

## しくみのメモ（開発用）
- 同期は «変わったメモだけ送る → サーバーの全部を受け取る»。同じメモを2人が直したら、あとから送ったほうが残る（`rev`）
- 消したメモは `deleted` の印を60日残して、ほかの端末からも消えるようにしている
- 共有中のくり返しリマインドは、サーバー（cron）が次の回へ進める。画面側は表示するだけ
- Web Push は RFC 8291（aes128gcm）＋ VAPID（ES256）を PHP の openssl で実装
